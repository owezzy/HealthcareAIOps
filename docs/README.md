# Documentation

The documentation follows the [Diátaxis](https://diataxis.fr/) framework: four kinds of page for four different needs. Pick the column that matches what you are trying to do.

| I want to… | Go to | Pages |
|---|---|---|
| **Learn** by running it | [Tutorials](tutorials/) | [Getting started](tutorials/getting-started.md) |
| **Do** a specific job | [How-to guides](how-to/) | [Deploy to owezzy-db](how-to/deploy-to-owezzy-db.md) · [Add the simulated node-2](how-to/add-simulated-node-2.md) · [Run a scenario](how-to/run-a-scenario.md) · [Cut a release](how-to/cut-a-release.md) · [Add a scenario](how-to/add-a-scenario.md) · [Add a database migration](how-to/add-a-database-migration.md) |
| **Look up** a fact | [Reference](reference/) | [Make targets](reference/make-targets.md) · [Configuration](reference/configuration.md) · [HTTP endpoints](reference/http-endpoints.md) · [Scenario file format](reference/scenario-format.md) |
| **Understand** why | [Explanation](explanation/) | [Project plan](explanation/healthcare-aiops-plan.md) · [Architecture](explanation/architecture.md) · [Inspiration and the book](explanation/inspiration.md) · [Decisions (ADRs)](adr/README.md) · [Frontend design](design/frontend-design.md) |

Other folders:

- [`blog/`](blog/series-plan.md): the build-in-public blog series plan.
- [`design/mockups/`](design/mockups/): OpenDesign mockups. Open `index.html` in a browser.
- [`archive/`](archive/): the original plans, kept for history. They are superseded.

Task tracking lives in beads, not in these docs: run `bd ready` to see what can start next.
